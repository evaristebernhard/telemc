# 团洲垸洪水演进与溃口模拟资料

本仓库保存团洲垸洪水演进、局部溃口模拟和验证案例的输入资料、配置文件、脚本及说明文档。

## 目录

- `目前方案与已有资料/已完成的全域洪水演进模拟/`：全域二维模拟案例、网格和边界输入
- `目前方案与已有资料/已完成的局部溃口模拟/`：局部溃口、Tingsanchali 验证及 GAIA 案例
- `目前方案与已有资料/团洲垸文献中提取的实测数据/`：实测流量、溃口和断面资料
- `目前方案与已有资料/主要的参考文献/`：参考论文和技术报告
- `目前方案与已有资料/下载的原始大地形/`：原始地形数据索引
- `目前方案与已有资料/团洲垸我处理过的全域地形/`：处理后的地形工程文件

模拟生成的结果文件、可执行文件、下载压缩包和 Windows 下载元数据未纳入 Git；这些文件仍保留在本地工作区。
